## Now

- `/dashboard/profile` is Photo / Profile / YouTube tabs (in-page, hash `#photo` `#profile` `#youtube`). Menu label is **Profile**. Edits display name, slug, markdown bio (live goldmark preview + Advanced editor), optional site photo (square crop, 15MB, `/media/avatars/`), circle-to-square frame, and PFP border styles (default/custom/pulse/strobe/fire/neon/orbit/chroma). Ring styles animate `border-color` only; orbit/chroma run on a wrapper `::after` (orbit: rounded silhouette offset; chroma: cyan/magenta offset + opacity). Thickness/blur on ring styles; chroma blur only; orbit neither. Dirty fields open a sticky Discard / Save bar in the form (safe-area + consent fallback); Save stays on the dashboard and returns to the active tab. Public roster pages render the bio as sanitized HTML. Under 640px the well is 100% and the tablist scrolls sideways. Roster list/detail put name + who beside a larger PFP (who on its own line); list cards are one link. `/team` and `/friends` intros are locked CMS markdown; hub admin Edit. Save and close on Pages returns to the public page or the list, matching where Edit was clicked. About cannot be deleted. Old slugs 302 until reused. Roster detail slideshows gallery photos (6s, arrows, 3 thumbs in a column on the right). `/dashboard/gallery` (logged-in **Gallery** menu) holds up to 10 photos (`data/gallery/`, `/media/gallery/`, original aspect, 15MB, long edge 1600); drop or Add photo (file picker) to add, drag to reorder. Click the slideshow image for a full-viewport overlay. `/photos` is the live union (slideshow without the thumb column + `ul.grid`, pager 6/12/18/24, no reload). `/videos`, `/team/{slug}`, and `/friends/{slug}` paginate clips 6/12/18/24 (default 6) via `?n=&p=`. YouTube tab: Connect YouTube until linked, then featured clip + Feed Filter; public `/videos` and roster pages show only that user's matching clips. Public site, OAuth, access queue (approve → friend), Discord-role FS Team + Friends (`DISCORD_FRIENDS_ROLE_ID`; YouTube-only friends OK), articles, clips, admin users, custom pages, Spot, Episodes, `-port`. `DISCORD_HUB_ADMIN_ROLE_ID` + `DISCORD_HOSTS_ROLE_ID` + `DISCORD_FRIENDS_ROLE_ID`. Former `member` rows are Friends; skater Discord role on login moves them to FS Team.
